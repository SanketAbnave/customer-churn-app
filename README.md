# 📊 Customer Churn Prediction App

## 📌 Project Overview
This project is a Machine Learning-based web application that predicts whether a customer is likely to churn (leave a service) or stay. The model is trained on customer data and deployed using Streamlit for real-time predictions.

---

## 🎯 Objective
The goal of this project is to:
- Identify customers at risk of churning
- Help businesses take proactive retention actions
- Provide an interactive interface for predictions

---

## 🧠 Machine Learning Models Used
- Logistic Regression (Baseline)
- Random Forest
- XGBoost (Final Model)

---

## ⚙️ Features & Techniques
- ✅ Data Cleaning & Preprocessing
- ✅ Handling Missing Values
- ✅ Encoding Categorical Variables
- ✅ Feature Scaling using StandardScaler
- ✅ Handling Imbalanced Data using SMOTE
- ✅ Model Training & Evaluation
- ✅ Hyperparameter Tuning
- ✅ Feature Importance Analysis

---

## 📊 Model Performance
- Improved Recall and F1-score for churn prediction
- Balanced performance using SMOTE
- XGBoost provided the best results

---

## 🌐 Web Application (Streamlit)
- User-friendly interface
- Real-time churn prediction
- Displays:
  - Churn / No Churn result
  - Probability score

---

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- XGBoost
- Imbalanced-learn (SMOTE)
- Streamlit
- Joblib
